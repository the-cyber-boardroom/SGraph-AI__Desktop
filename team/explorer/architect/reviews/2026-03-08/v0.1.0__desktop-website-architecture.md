# Architect Review: desktop.sgraph.ai Website

**Date:** 2026-03-08
**Version:** v0.1.0

## Purpose

The `desktop.sgraph.ai` website serves as the official download page for SGraph Desktop. It provides:

1. Direct download link pointing to the latest GitHub Release
2. Feature overview and site descriptions
3. System requirements
4. Visual preview of the app

## Architecture Decisions

### 1. Static HTML — No Build Step

The website is a single `index.html` with inline CSS. No JavaScript framework, no build step. This matches the project's "vanilla JS, no frameworks" philosophy and can be hosted on any static file server (GitHub Pages, Cloudflare Pages, Netlify, or any CDN).

### 2. GitHub Releases as Download Source

The download button links to `https://github.com/SGraph-AI/Desktop/releases/latest`, which always redirects to the most recent release. This means:

- No manual URL updates needed when new versions ship
- Users can also browse all releases at `/releases`
- Direct DMG links work: `https://github.com/SGraph-AI/Desktop/releases/download/v0.1.0/SGraph-Desktop_0.1.0_aarch64.dmg`

### 3. Hosting Options

| Option | Pros | Cons |
|--------|------|------|
| **GitHub Pages** | Free, automatic from repo | Limited to github.io subdomain unless custom domain configured |
| **Cloudflare Pages** | Free, fast CDN, easy custom domain | Requires Cloudflare account |
| **Netlify** | Free tier, easy deploy | Third-party dependency |

**Recommendation:** GitHub Pages from a `docs/` folder or dedicated branch, with `desktop.sgraph.ai` CNAME.

### 4. Download Link Strategy

For the download button to link directly to the DMG file (not the release page), use the GitHub Release asset URL pattern:

```
https://github.com/SGraph-AI/Desktop/releases/latest/download/SGraph-Desktop_0.1.0_aarch64.dmg
```

Note: The `/latest/download/` path requires the asset filename to be consistent across releases. The Tauri build produces `SGraph Desktop_<version>_aarch64.dmg` — we should standardise this.

## Security Considerations

- No analytics or tracking scripts
- No external dependencies except Google Fonts (Inter)
- Could self-host Inter font to eliminate even that dependency
- Download links point to GitHub (trusted source)

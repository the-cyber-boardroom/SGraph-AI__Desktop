## Step-by-Step: Export Certificate and Configure GitHub Secrets

### Step 1: Export the .p12 certificate from Keychain Access

1. Open **Keychain Access** on your Mac
2. In the sidebar, select **login** keychain → **My Certificates** category
3. Find **"Developer ID Application: Dinis Miguel Cavaco Silva da Cruz (M3T6BV9F8M)"**
4. Right-click → **Export...**
5. Save as `.p12` format
6. Set a strong password (you'll need this for the GitHub secret)

### Step 2: Base64-encode the certificate

```bash
base64 -i ~/Desktop/certificate.p12 | pbcopy
```

This copies the base64 string to your clipboard.

### Step 3: Add GitHub repository secrets

Go to **GitHub → SGraph-AI__Desktop → Settings → Secrets and variables → Actions** and add:

| Secret Name | Value |
|-------------|-------|
| `APPLE_CERTIFICATE` | The base64-encoded `.p12` from Step 2 |
| `APPLE_CERTIFICATE_PASSWORD` | The password you set in Step 1 |
| `APPLE_SIGNING_IDENTITY` | `Developer ID Application: Dinis Miguel Cavaco Silva da Cruz (M3T6BV9F8M)` |
| `APPLE_ID` | Your Apple ID email address |
| `APPLE_TEAM_ID` | `M3T6BV9F8M` |
| `APPLE_PASSWORD` | An **app-specific password** (see Step 4) |

### Step 4: Create an app-specific password for notarisation

1. Go to https://appleid.apple.com → **Sign-In and Security** → **App-Specific Passwords**
2. Click **Generate** → name it "SGraph Desktop CI"
3. Copy the generated password → use it for the `APPLE_PASSWORD` secret

### Step 5: Update Tauri config for signing (already prepared)

The CI pipeline (`ci-pipeline.yml`) already accepts all these secrets. Once configured, Tauri will automatically sign and notarise the app during the build step.

To enable signing in the Tauri build, the build step needs these environment variables (to be added to CI):

```yaml
- name: Build Tauri app
  env:
    APPLE_CERTIFICATE: ${{ secrets.APPLE_CERTIFICATE }}
    APPLE_CERTIFICATE_PASSWORD: ${{ secrets.APPLE_CERTIFICATE_PASSWORD }}
    APPLE_SIGNING_IDENTITY: ${{ secrets.APPLE_SIGNING_IDENTITY }}
  run: cargo tauri build --target aarch64-apple-darwin

- name: Notarise
  if: env.APPLE_ID != ''
  env:
    APPLE_ID: ${{ secrets.APPLE_ID }}
    APPLE_TEAM_ID: ${{ secrets.APPLE_TEAM_ID }}
    APPLE_PASSWORD: ${{ secrets.APPLE_PASSWORD }}
  run: |
    xcrun notarytool submit \
      src-tauri/target/aarch64-apple-darwin/release/bundle/dmg/*.dmg \
      --apple-id "$APPLE_ID" \
      --team-id "$APPLE_TEAM_ID" \
      --password "$APPLE_PASSWORD" \
      --wait
```

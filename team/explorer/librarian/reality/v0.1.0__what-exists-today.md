## Infrastructure

- [x] CI/CD: base pipeline (`.github/workflows/ci-pipeline.yml`) — matrix strategy builds both aarch64 (macos-14) and x86_64 (macos-13) in parallel, increment-tag job, configurable artifact retention
- [x] CI/CD: dev pipeline (`.github/workflows/ci-pipeline__dev.yml`) — triggers on push to dev, increments minor tag, **7-day artifact retention**
- [x] CI/CD: main pipeline (`.github/workflows/ci-pipeline__main.yml`) — triggers on push to main, increments minor tag, **90-day artifact retention (default)**
- [x] CI/CD: release workflow (`.github/workflows/release.yml`) — matrix builds both architectures, signs, notarises, creates single GitHub Release with both DMGs
- [x] **Dual-architecture support** — builds for Apple Silicon (aarch64-apple-darwin, macos-14) and Intel (x86_64-apple-darwin, macos-13)
- [x] **Release notes** include download table distinguishing Apple Silicon vs Intel DMGs
- [x] Auto-tagging via `owasp-sbot/OSBot-GitHub-Actions/.github/actions/git__increment-tag@dev`
- [x] **Code signing** — Apple Developer certificate imported in CI from GitHub Secrets
- [x] **Notarisation** — `xcrun notarytool submit` + `xcrun stapler staple` in CI
- [x] DMG distribution — signed DMGs (both architectures) attached to GitHub Release as downloadable assets
- [x] GitHub Releases as official download source (direct DMG links from release assets)

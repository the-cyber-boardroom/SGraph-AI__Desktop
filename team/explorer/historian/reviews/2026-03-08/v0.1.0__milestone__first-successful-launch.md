# Milestone: First Successful Launch on macOS

**Date:** 2026-03-08
**Version:** v0.1.0
**Verified by:** Dinis Cruz (MacBook Air M2, macOS Tahoe 26.2)

---

## What Happened

SGraph Desktop v0.1.0 was built via GitHub Actions CI, downloaded as a DMG artifact, and successfully launched on a real macOS machine for the first time.

All four SGraph ecosystem sites loaded correctly in native webviews:
- **SG/Send** (`send.sgraph.ai`)
- **SG/Vault** (`vault.sgraph.ai`)
- **SG/Workspace** (`workspace.sgraph.ai`)
- **SG/Tools** (`tools.sgraph.ai`)

## What Works

- Tauri v2 app shell with sidebar navigation (4 site icons + settings)
- Native macOS title bar displaying "SGraph Desktop"
- Webview loading live `*.sgraph.ai` URLs
- Sidebar switching between sites
- Status bar showing active URL and connection state ("Ready")
- Aurora dark theme matching SGraph brand
- CI build producing aarch64 DMG artifact (2.69 MB)
- App runs on Apple Silicon (M2) natively

## Known Issue: Gatekeeper Quarantine

The app is **unsigned** — macOS shows "is damaged and can't be opened" when launched after download. Workaround:

```bash
xattr -cr "/path/to/SGraph Desktop.app"
```

**Root cause:** No Apple Developer certificate configured in CI. The release workflow has signing steps ready — just needs secrets configured in the GitHub repo.

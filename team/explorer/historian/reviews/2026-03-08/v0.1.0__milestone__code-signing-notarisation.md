# Milestone: Code Signing & Notarisation Working

**Date:** 2026-03-08
**Version:** v0.1.0
**Verified by:** Dinis Cruz (MacBook Air M2, macOS Tahoe 26.2)

---

## What Happened

SGraph Desktop v0.1.0 is now **fully signed and notarised** by Apple. When downloaded and opened, macOS shows the standard Gatekeeper dialog:

> "SGraph Desktop 3" is an app downloaded from the internet. Are you sure you want to open it?
> Chrome downloaded this file today at 10:59. Apple checked it for malicious software and none was detected.

This is the **same dialog shown by Claude Desktop, Chrome, VS Code, and all properly signed apps** distributed outside the Mac App Store. The blue "Open" button is present — no scary warnings, no System Settings workaround needed.

## Before vs After

| Aspect | Before (unsigned) | After (signed + notarised) |
|--------|-------------------|---------------------------|
| Dialog | "is damaged and can't be opened" | "downloaded from the internet — are you sure?" |
| Action required | `xattr -cr` in Terminal | Click blue "Open" button |
| Apple message | "Apple cannot verify this app" | "Apple checked it for malicious software and none was detected" |
| User experience | Confusing, scary, terminal knowledge required | Standard, expected, one-click |

## What This Means

1. **No more `xattr -cr` workaround** — users just click Open
2. **Apple has verified** the app contains no known malware
3. **Same trust level** as major apps like Claude Desktop
4. **Distribution-ready** — the DMG can now be downloaded and used by anyone on macOS 13+

## Technical Details

- **Signing identity:** Apple Developer ID Application certificate
- **Notarisation:** `xcrun notarytool submit` + `xcrun stapler staple`
- **CI pipeline:** Automated in `ci-pipeline.yml` — signs during build, notarises after
- **Secrets configured:** `APPLE_CERTIFICATE`, `APPLE_CERTIFICATE_PASSWORD`, `APPLE_SIGNING_IDENTITY`, `APPLE_ID`, `APPLE_TEAM_ID`, `APPLE_PASSWORD`

## Impact

This removes the #1 blocker for user distribution. Combined with the GitHub Release workflow, SGraph Desktop can now be downloaded and launched by any macOS user without special knowledge or Terminal commands.

# Designer Review: desktop.sgraph.ai Website

**Date:** 2026-03-08
**Version:** v0.1.0 (First Pass)

## Design Direction

The website follows the SGraph **Aurora dark theme** — consistent with the desktop app itself. Dark backgrounds with the signature teal/green accent (`#06d6a0`).

## Visual Hierarchy

1. **Hero** — Large headline, download button, system requirements
2. **App Preview** — Mock-up of the desktop app showing sidebar + content area
3. **Features** — 6-card grid explaining why users should download
4. **Sites** — 4-card grid showing the four SGraph tools
5. **Requirements** — System requirements list
6. **Footer** — GitHub link, SGraph branding

## Design Tokens

| Token | Value | Usage |
|-------|-------|-------|
| `--bg-primary` | `#0a0e17` | Page background |
| `--bg-secondary` | `#111827` | Card/section backgrounds |
| `--bg-card` | `#1a2332` | Feature cards |
| `--accent` | `#06d6a0` | CTA buttons, highlights |
| `--text-primary` | `#e2e8f0` | Headings |
| `--text-secondary` | `#94a3b8` | Body text |
| `--border` | `#1e293b` | Card borders |

## Typography

- **Font:** Inter (via Google Fonts)
- **Hero:** 48px bold
- **Section headings:** 32px
- **Body:** 14-15px
- **Meta text:** 13px

## Responsive

- Flexbox/grid layout adapts to mobile
- Hero text scales down on small screens
- Feature grid collapses to single column

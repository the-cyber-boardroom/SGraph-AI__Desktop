Why SGraph Desktop?

🚀

Native Performance

Built with Tauri v2 and system WebKit. Lightweight (~3 MB), fast startup, low memory usage. No Electron bloat.

🔒

macOS Keychain

Tokens and secrets stored in the macOS Keychain, not localStorage. Your credentials are protected by the OS.

🛡

Privacy First

Zero analytics. Zero tracking. Zero telemetry. The app connects only to *.sgraph.ai — nothing else.

☰

All Sites, One App

Send, Vault, Workspace, and Tools — switch between them instantly from the sidebar. No browser tabs needed.

✅

Signed & Notarised

Every release is signed with an Apple Developer certificate and notarised. macOS confirms it's safe to open.

⚙

macOS Integration

Dock icon, native menu bar, keyboard shortcuts, and drag-and-drop file uploads. Feels like a native Mac app.
